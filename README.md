# Environmental Dynamics and Persistent Evolutionary Novelty

This private repository distributes the complete research package as [cas_oee_research.zip](cas_oee_research.zip). Download and extract the archive to recover the full project tree, including simulation code, frozen protocol, tests, raw replicate data and seeds, manifests, integrity audit, analysis outputs, figures, and manuscript draft.

## Status and result

This is an exploratory finite-model computational study, not a demonstration of open-ended evolution. It contains 240 planned simulation trajectories. Validation and raw-data integrity checks passed.

The primary fast-versus-static Environment × Network difference-in-differences estimate was −0.0078 persistent events per 1,000 eligible births (95% seed-block bootstrap interval: −0.0234 to 0.0078). The interval includes zero; these results do not resolve a clear interaction. The timescale ratio was not analyzed because adaptive recovery time was not independently calibrated.

After extraction, see the package's own README for exact reproduction steps and the documented post-run censoring correction. The GitHub root intentionally keeps the complete archive as a single file; its included workflow is not active at this archive-only root.
